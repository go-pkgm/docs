# go-fft docs

Documentation site for [go-fft](https://github.com/go-fft/fft) — built with
MkDocs Material, versioned with [mike](https://github.com/jimporter/mike), and
served at <https://go-fft.github.io/docs/>.

## Local preview

```sh
pip install -r requirements.txt
mkdocs serve
```

Pushing to `main` deploys the `latest` version to the `gh-pages` branch via
GitHub Actions; GitHub Pages serves it under `/docs/`.
